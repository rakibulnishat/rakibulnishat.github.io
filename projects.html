Research Projects

Selected research and engineering projects spanning embedded AI, medical imaging, and IoT systems.

Self-Charging Surveillance Robot with Owner Recognition (SCSR-ORS) 2024 – 2025
B.Sc. Thesis Robotics Computer Vision UWB/IMU Raspberry Pi YOLOv4-tiny
Designed a mobile surveillance robot on Raspberry Pi with autonomous wireless charging via UWB/IMU-fused Extended Kalman Filter navigation. Implemented YOLOv4-tiny owner face recognition achieving AUC = 0.911 for biometric access control.
MRSI Missing Data Estimation — Mask-Free Deep Learning 2026
Medical AI U-Net MRI Deep Learning
Designed a progressive U-Net architecture for estimating missing spectral data in Magnetic Resonance Spectroscopic Imaging (MRSI) without requiring explicit masks. Targets clinical MRI pipelines in resource-limited environments, contributing to affordable diagnostic infrastructure.
Mango Leaf Disease Classifier (MangoScan) 2026
ResNet-50 Grad-CAM LIME Docker Hugging Face Spaces Agriculture AI
Trained ResNet-50 on an 8-class mango disease dataset; deployed on Hugging Face Spaces via Docker with Grad-CAM and LIME explainability. Targeted low-connectivity environments for smallholder farmer adoption in Bangladesh.
MediAssist BD — Offline Medical Assistant App 2026
LLM Qwen2-1.5B MNN Android / Kotlin RxNorm API Healthcare
Built a fully offline Android medical assistant for Bangla and English-speaking users using Qwen2-1.5B LLM deployed via Alibaba's MNN (Mobile Neural Network) inference engine with JNI integration in Kotlin. Integrated RxNorm API for drug database connectivity. Targets healthcare access in rural low-connectivity settings of Bangladesh.
Mental Health AI — Multi-Label Depression & Anxiety Classifier 2026
RoBERTa NLP FastAPI Hugging Face Medical AI
Developed a multi-head RoBERTa-based classifier with three independent binary output heads for depression detection, anxiety detection, and safety-critical flagging. Achieved Depression F1 = 0.82 and Anxiety F1 = 0.86 on the held-out evaluation; deployed as a REST API via FastAPI on Hugging Face Spaces.
Multi-Modal Embedded Vision Framework for Edge AI 2024 – 2025
YOLOv4-tiny CNN Raspberry Pi Edge AI IEEE ICCIT 2025
Built a real-time object detection, facial emotion recognition, and biometric identification pipeline on a low-power edge platform (Raspberry Pi). Optimized inference latency for GPU-free deployment by combining YOLOv4-tiny and lightweight CNNs in a single embedded pipeline. Published at 28th IEEE ICCIT 2025.
GSM-IoT Smart Pet Feeder with Mobile App 2024
Arduino SIM800L GSM IoT Android IEEE SPICSCON 2025
Developed an Arduino + SIM800L GSM IoT device achieving 98% SMS command success rate and ±2.67% portion dispensing variance. Designed a companion Android app via MIT App Inventor for remote feeding control and real-time status monitoring. Published at IEEE SPICSCON 2025.
IoT Smart Irrigation System with Cloud Monitoring 2024 – 2025
ESP32 IoT Cloud Dashboard Agriculture IEEE QPAIN 2026
Engineered an ESP32-based automated irrigation system with cloud dashboard and mobile alerts for smallholder farmers. Monitors soil moisture, soil pH, rainfall, temperature, and humidity in real time. Published at QPAIN 2026.
Self-Balancing Two-Wheeled Robot Using PID Controller 2024
Arduino Nano MPU6050 IMU PID Control IEEE QPAIN 2026
Designed and implemented a two-wheeled self-balancing robot with real-time discrete-time PID control; validated stability under dynamic load conditions. Published at IEEE QPAIN 2026.
